The Problem

Hard to reason
about strategy

Balatro is a roguelike poker game where scoring scales multiplicatively. The right discard or hand choice can mean the difference between clearing a round and losing the run — but it's difficult to reason systematically about what's actually strong.

Get better at Balatro, within the game rules, without cheating.

The Approach

Bot as teacher

Build a simulator, run agents of increasing sophistication, and analyze their decision traces. The bot doesn't play for us — it plays ahead of us, surfacing strategies a human might not discover through trial and error alone.

Input
Game state: hand, deck, chips scored, resources left
Output
Win rate, chip scores, and annotated strategy traces
Constraint
Standard 52-card rules; no lookahead into draw order
Goal
Pass 2 rounds: 300 chips, then 500 chips

System Design

The Environment — nouns, then verbs

Start with what exists; then describe what happens to it.

Nouns · State
  • 7 cards visible to the agent each turn
  • remaining cards — counts known, order hidden
  • spent cards, out of play for the round
  • play or discard 1–5 cards from hand
  • hands left (4), discards left (4) per round
  • 300 chips (round 1) · 500 chips (round 2)
Verbs · Transitions
  • score the poker hand → add chips → redraw
  • remove cards → redraw · never ends the round
  • base_chips × mult from hand-type lookup table
  • chips_scored ≥ target before hands_left = 0
  • hands exhausted before reaching target
  • fresh deck, reset resources, higher target

Motivation

Why move to learned policy?

i.
Scripted bots encode human intuitions. A learned policy can discover non-obvious trade-offs — like when not to chase a flush — that heuristics miss.
ii.
The action space is large (up to C(7,5)×2 actions per turn). Pruning helps, but a Q-function can learn to deprioritize weak actions rather than hard-cut them.
iii.
Reward signal is clean: chips scored per action is direct, dense, and well-defined. This is an ideal RL testbed.
RLQBot Architecture
State features — hand composition, outs to each hand type, chips scored, resources remaining, round target gap
Action features — hand type achievable, score estimate, cards used, discard vs play flag
Network — small PyTorch Q-network; state × action → scalar Q-value
Training — DQN-style with replay buffer; ε-greedy exploration; 500 episodes × 3 seeds
Reward — chips gained per action; round completion bonus

How the analyzer works

Discard counting
→ intent inference

i.
Count consecutive discards — two or more in a row signals a hunt is underway.
ii.
The hand type played immediately after the discard run reveals the hunt target — straight, flush, or full house.
iii.
Score the game by what was hunted, whether it succeeded, and how many discards it cost — more discards for the same result = more deliberate.

Takeaways

What the bot taught us

✓
The scripted baseline ladder confirms the environment is sensitive enough to rank policies. Each deliberate improvement produces measurable gain.
✓
RL doubles scripted win rate on easy (54% vs 26%), learning premium-hand hunting — trading guaranteed pairs for flushes and straights that score 3–4× more.
△
On hard, RL accumulates more chips than any scripted bot but doesn't close runs — a reward shaping gap: chips/action ≠ round completion.
Open Questions
Can reward shaping — penalizing a chip shortfall at round end — unlock hard-mode completion?
Does the hunt-first strategy transfer to harder presets, or does the higher target demand a different approach?
Would richer Balatro mechanics (jokers, mult stacking) change the learned strategy qualitatively?
The bot earns its keep as a teacher — hard mode is the next lesson.
